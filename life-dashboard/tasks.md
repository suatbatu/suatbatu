# Tasks

This file is yours. Edit it whenever, from anywhere — GitHub's web editor works
fine on a phone. The morning briefing reads it and builds **Top Priorities** and
**Tasks Due** from it.

## Syntax

```
- [ ] Something I need to do            !1  @2026-08-20  #money
      ^ unchecked = open                 ^   ^            ^
                            priority 1-3 ┘   │            └ optional tag
                                 due date ───┘
```

- `- [ ]` open · `- [x]` done (done items are ignored after 14 days, delete freely)
- `!1` urgent · `!2` normal · `!3` someday — no marker means `!2`
- `@YYYY-MM-DD` due date — drives the countdown ledger
- `#tag` — free-form, e.g. `#money` `#health` `#forestguard` `#pillpilot` `#ev`
- Anything under `## Someday` is never surfaced as a priority, only browsable.
